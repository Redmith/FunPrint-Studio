# FunPrint Studio — Editor térmico

Editor térmico para impresoras C9, 58 mm, 80 mm y más.

Página en vivo (GitHub Pages): https://redmith.github.io/FunPrint-Studio/

## Qué hace

- Diseña collares / tiras térmicas con fotos, texto, rectángulos, círculos y líneas.
- Importa fotografías, las mejora en lote y arma collages (clásico, libre, editorial, vintage).
- Vista previa térmica con tramado, para ver cómo sale impreso en 1 bit.
- Exporta PNG monocromo, PNG del diseño, JPG térmico y proyecto editable .fps.
- Biblioteca de plantillas y trabajos, con historial (deshacer / rehacer).
- Impresión directa por Bluetooth (experimental, ESC/POS) para impresoras térmicas compatibles.

## Uso

Abrí la página, elegí el modelo de impresora (C9 57 mm, genérica 58 mm, POS 80 mm, etc.), importá las fotos y armá el collar. Todo corre en el navegador, sin servidor: no se sube nada a ningún lado.
